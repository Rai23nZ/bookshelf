How the file is built
Goodreads’ own column set, comma-separated, UTF-8. Decimal ratings are rounded to whole stars; fields with commas are quoted; each row keeps its shelf (read, currently-reading, to-read) so nothing lands on the wrong pile. Re-importing the same file is safe.
